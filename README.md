Análisis de Movilidad Urbana y Productividad Económica (2024)
Este repositorio contiene el análisis integral realizado para el Banco de Desarrollo, donde se explora la relación entre la congestión vehicular y los indicadores macroeconómicos de las principales ciudades del mundo.

El proyecto integra dos fuentes de datos críticas: métricas de tráfico en tiempo real (índices de congestión y retrasos) y datos económicos de productividad (PIB per cápita y tasas de desempleo).

🧠 Objetivo del análisis
Estandarización de Datos: Limpiar y unificar métricas de ciudades provenientes de distintas fuentes globales.

Integración de Datasets: Realizar un merge eficiente entre datos de tráfico y KPIs económicos usando llaves compuestas.

Análisis Estadístico: Evaluar la distribución de la congestión mediante Histogramas y Boxplots para identificar ciudades atípicas.

Visualización Estratégica: Generar gráficos de doble eje para comparar visualmente si una alta productividad económica (PIB) está correlacionada con una mayor ineficiencia en la movilidad (Traffic Index).

Insights para Políticas Públicas: Proveer una base de datos limpia para la toma de decisiones en infraestructura urbana.
